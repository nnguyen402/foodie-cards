# Card asset sources

| Asset | Source | Permission |
|---|---|---|
| `layout.json` | Window positions exported by the team's frame generator (`gen.html`, 750×1050 canvas). | Team-made original work. |
| Common, Rare and Ultra Rare frames | Drawn in code by `src/features/cards/CardFrame.tsx`, a React Native port of the same team-written generator. No image files and no AI-generated artwork. | Team-made original work. |

No restaurant logos or photos are bundled yet. Cards draw a themed fallback until
prepared images are added here; record each image's source and permission in this
table when it is.
